# Vitest

1. Use `vitest run` for running tests in CI
2. Use `vitest` for watch mode during development
3. Use `vitest.config.ts` for configuration
4. Use `describe` and `it` for test organization
5. Use `expect` for assertions
6. Use `beforeEach` and `afterEach` for setup/teardown
7. Use `beforeAll` and `afterAll` for global setup/teardown
8. Use `vi.mock` for mocking modules
9. Use `vi.fn()` for creating mock functions
10. Use `vi.spyOn()` for spying on functions
11. Use `test.each` for parameterized tests
12. Use `test.skip` to skip tests temporarily
13. Use `test.only` to run specific tests during development
14. Use `@vitest/coverage/v8` for code coverage
15. Use `vitest run --coverage` for coverage reports
