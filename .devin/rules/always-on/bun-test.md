# Bun Test

1. Use `bun test` for running tests in CI
2. Use `bun test --watch` for watch mode during development
3. Use `bunfig.toml` `[test]` section for configuration
4. Use `describe` and `it` from `bun:test` for test organization
5. Use `expect` from `bun:test` for assertions
6. Use `beforeEach` and `afterEach` from `bun:test` for setup/teardown
7. Use `beforeAll` and `afterAll` from `bun:test` for global setup/teardown
8. Use `mock.module` from `bun:test` for mocking modules
9. Use `mock()` from `bun:test` for creating mock functions
10. Use `spyOn` from `bun:test` for spying on functions
11. Use `test.each` for parameterized tests
12. Use `test.skip` to skip tests temporarily
13. Use `test.only` to run specific tests during development
14. Use `bun test --coverage` for coverage reports
