# Bunup

1. Use `bunup` for bundling TypeScript libraries
2. Use `bunup.config.ts` for configuration
3. Use `bunup` for building instead of `tsc` or `esbuild`
4. Define entry points in `bunup.config.ts`
5. Use `bunup --watch` for watch mode during development
6. Use `bunup --minify` for production builds
7. Use `bunup --sourcemap` for source maps
8. Configure output formats (esm, cjs) in config
9. Use `external` option for dependencies that should not be bundled
10. Use `plugins` for custom bundling logic
11. Use `bunup` for CLI tools with `bin` configuration
12. Use `bunup` for library packages with `main` and `types` fields
13. Configure `dts` for automatic type declaration generation
14. Use `bunup` for fast bundling with Bun's native bundler
15. Use `bunup` instead of `tsup` or `tsdown` when using Bun runtime
